1- تنزيل ffmpeg

إذا كنت تستخدم توزيعة Red Hat-based (Fedora / RHEL / CentOS)

نسخ
# 1. فعل مستودعات RPM Fusion
sudo dnf install https://download1.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm
sudo dnf install https://download1.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

# 2. حدث المستودعات
sudo dnf update

# 3. نزل FFmpeg Full Build
sudo dnf install ffmpeg ffmpeg-devel

إذا كنت تستخدم توزيعة Debian-based (Ubuntu / Debian / Mint)

نسخ
sudo apt update sudo apt install -y software-properties-common wget gnupg apt-transport-https # استخدم PPA على Ubuntu if [ -f /etc/lsb-release ]; then sudo add-apt-repository -y ppa:jonathonf/ffmpeg-4 fi # استخدم deb-multimedia على Debian if [ -f /etc/debian_version ]; then sudo wget https://www.deb-multimedia.org/pool/main/d/deb-multimedia-keyring/deb-multimedia-keyring_2016.8.1_all.deb sudo dpkg -i deb-multimedia-keyring_2016.8.1_all.deb fi sudo apt update sudo apt install -y ffmpeg # Snap بديل لأي توزيعة حديثة sudo snap install ffmpeg

للتأكد اكتب ffmpeg -version

4- أوامر فصل الموسيقى

قم بعمل مجلد Scripts في C::

افتح برنامج الملاحظات notepad واكتب هذا

احفظه في المجلد C:\Scripts باسم remove_music.ps1

افتح Registry Editor ثم HKEY_CLASSES_ROOT ثم * ثم shell ثم انقر الزر الأيمن من الفأرة ثم New ثم Key ثم Remove Music

ثم اضغط على Remove Music ثم انقر الزر الأيمن من الفأرة ثم New ثم Key ثم command

ثم اضغط على command ثم اضغط على default مرتين واكتب

نسخ
powershell.exe -NoExit -NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\remove_music.ps1" "%1"

ثم اضغط على OK

تم ✅
