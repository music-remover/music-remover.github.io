مزيل الموسيقى

1- تنزيل بايثون

اضغط هنا (حوالي 28.5 ميجا)

اضغط Add to path أثناء التنزيل

اضغط Close بعد التنزيل

للتأكد افتح cmd واكتب python --version ثم pip --version

تم ✅

2- تنزيل ffmpeg (لفصل الصوت عن الفيديو)

اضغط هنا (حوالي 146 ميجا)

اختر الملف ffmpeg-release-full.7z أو اضغط هنا مباشرةً

فك ضغط الملف Extract all

سيظهر لك مجلد داخل المجلد المفكوك

أعد تسمية المجلد الداخلي (الذي بداخله ملفات كثيرة) إلى ffmpeg

انقل المجلد إلى C: بحيث يصبح C:\ffmpeg

أضف المجلد C:\ffmpeg\bin إلى متغيرات النظام

للتأكد افتح cmd واكتب ffmpeg -version

تم ✅

3- تنزيل demucs

افتح cmd واكتب pip install demucs (حوالي 137.2 ميجا)

ثم تنزيل باقي المتطلبات (حوالي 2.4 جيجا) ⛔️

نسخ
pip install torch==2.5.1+cu121 torchvision==0.20.1+cu121 torchaudio==2.5.1+cu121 --index-url https://download.pytorch.org/whl/cu121

تم ✅

4- أوامر فصل الموسيقى

قم بعمل مجلد Scripts في C::

افتح برنامج الملاحظات notepad واكتب هذا

احفظه في المجلد C:\Scripts باسم remove_music.ps1

افتح Registry Editor ثم HKEY_CLASSES_ROOT ثم * ثم shell ثم انقر الزر الأيمن من الفأرة ثم New ثم Key ثم Remove Music

ثم اضغط على Remove Music ثم انقر الزر الأيمن من الفأرة ثم New ثم Key ثم command

ثم اضغط على command ثم اضغط على default مرتين واكتب

نسخ
powershell.exe -NoExit -NoProfile -ExecutionPolicy Bypass -File "C:\Scripts\remove_music.ps1" "%1"

ثم اضغط على OK

تم ✅
